# Changelog

## 1.0.0 — 2026-10-31

- Shows the code of a pending inspection, its deadline and the time left; dark otherwise.
- Vibration alarm on new inspections, with reminders until a button is pressed.
- Status screen on a button press: Wi-Fi, battery, locked/unlocked, username.
- Setup portal on the phone: up to 3 Wi-Fi networks, server, login, English or German.
- Deadlines in the timezone set on the wearer's account.
- Works with any ChastityTracker instance on HTTPS with a public CA.
- Factory reset from the setup page.
- Prebuilt firmware and a browser flasher.
- Case with or without a belt clip; without it, the lid carries a two-colour logo.
