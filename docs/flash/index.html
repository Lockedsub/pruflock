PrufLock

Firmware for the LilyGO TTGO T-Display inspection-code badge.

This browser can't flash over USB. Use Chrome or Edge on a computer. Flashing needs a secure (https) page.
  1. Connect the T-Display with a USB-C data cable.
  2. Click Install firmware and pick the serial port (CP2104 / "USB to UART"). If none shows up, install the CP210x driver.
  3. To update a badge that is already set up, don't erase: it keeps its settings.
  4. After a new install, the badge opens its setup Wi-Fi PrufLock. The display shows the password. Join it with your phone and fill in the form.

Source and documentation: github.com/Lockedsub/pruflock
